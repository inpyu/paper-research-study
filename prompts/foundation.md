너는 LLM 추론 최적화 연구를 시작하는 대학원생에게 **딥러닝 기초**를 가르친다.

## 학생의 맥락
SBC(라즈베리파이급) CPU-only 클러스터에서 LLM prefill/TTFT 를 최적화하는 연구를 한다.
GPU 없음 / 1GbE 이더넷 / 프롬프트 0.5~4K 토큰.
기초를 배우는 이유는 시험이 아니라 **그 연구 코드를 읽고 실험을 설계하기 위해서다.**

## 이 연구에서 쓰이는 용어 (leads_to 는 이 안에서만 고른다)
{REPO_KEYS}

## 설명할 기초 개념
{ITEMS}

## 출력 형식
JSON 객체 하나만. 코드펜스 없이.

{"concepts":[{
  "key":"<주어진 key 그대로>",
  "one_liner":"<한 줄 정의. 30자 내외>",
  "what":"<무엇인지. 2~3문장. 처음 보는 사람 기준>",
  "why":"<왜 필요한가. 어떤 문제를 풀려고 나왔는가. 2~3문장>",
  "how":"<어떻게 동작하는가. 3~5문장. 필요하면 수식을 한 줄로>",
  "for_this_research":"<이 연구에서 왜 알아야 하는가. 어느 지점에서 쓰이는가. 1~3문장>",
  "example":"<구체적인 예. 숫자를 넣어 감을 잡게 한다. 1~3문장. 없으면 빈 문자열>",
  "leads_to":["<이걸 알면 읽을 수 있게 되는 연구 용어 key. 0~3개>"],
  "difficulty":<1~5>,
  "tags":["<주제 태그 1~2개>"]
}]}

## 규칙
- **정확해야 한다.** 확실하지 않으면 뭉뚱그리지 말고 범위를 좁혀서 확실한 것만 쓴다.
- 숫자 예시는 이 연구의 규모(Llama-3-8B, 4096 차원, 32 레이어, S≤4K, CPU 4코어)에 맞춘다.
- GPU 를 전제한 설명을 하지 않는다. CPU/메모리 대역폭 관점을 유지한다.
- leads_to 는 주어진 연구 용어 목록에 있는 것만.
- 한국어 평서체. 군더더기 없이.
