너는 LLM 추론 최적화 연구를 시작하는 대학원생의 **기초 학습 커리큘럼**을 설계한다.

## 목표
이 학생은 SBC(라즈베리파이급) CPU-only 클러스터에서 LLM prefill/TTFT 를 최적화하는
연구를 하고 있다. 연구 노트에는 아래 용어들이 이미 정의되어 있는데,
**그 아래 단계의 기초가 비어 있다.** 그 기초를 단계별로 설계하라.

## 단계 구성 (이 흐름을 따르되 개수는 스스로 정한다)
- stage 0 · 수학과 계산의 기초 — 벡터·행렬, 행렬곱, 부동소수점, 메모리와 대역폭
- stage 1 · 신경망의 기초 — 퍼셉트론부터 학습까지
- stage 2 · 시퀀스 모델과 트랜스포머 — 토큰화·임베딩·self-attention·FFN
- stage 3 · LLM 과 추론 — autoregressive 생성, 캐싱, 샘플링
- stage 4 · 성능과 시스템 — 병목 분석, 양자화, 병렬화, 통신
- 그다음이 위의 연구 용어들이다

## 출력 형식
JSON 객체 하나만. 코드펜스 없이.

{"stages":[{"stage":<정수>,"title":"<단계 제목>","goal":"<이 단계를 마치면 무엇을 할 수 있는가. 1문장>",
  "concepts":[{"key":"<영소문자·공백 슬러그. 예: matrix multiplication>",
               "name":"<표시 이름. 한국어 또는 통용 영어>",
               "one_liner":"<한 줄 정의. 30자 내외>",
               "prerequisites":["<같은 커리큘럼 안의 앞선 key. 0~2개>"],
               "leads_to":["<이 개념이 필요해지는 연구 용어 key. 위 목록에서만. 0~3개>"],
               "tags":["<주제 태그 1~2개>"],
               "difficulty":<1~5>}]}]}

## 규칙
- 단계당 개념 5~9개. 전체 30~45개.
- **이미 정의된 연구 용어와 같은 개념을 다시 만들지 않는다.** 겹치면 leads_to 로 잇는다.
- prerequisites 는 같은 커리큘럼의 **앞 단계 또는 같은 단계의 앞선 개념**만.
- CPU-only / 엣지 추론 맥락에서 실제로 필요한 것만 넣는다.
  학습(training) 자체는 stage 1 에서 원리 이해에 필요한 만큼만 다루고,
  추론(inference)에 무게를 둔다.
- 한국어. 평서체.
