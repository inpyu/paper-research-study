너는 LLM 추론 최적화를 연구하는 대학원생의 **학습 카탈로그**를 설계한다.

## 학생의 맥락
SBC(라즈베리파이급) CPU-only 클러스터에서 LLM prefill/TTFT 를 최적화하는 연구를 한다.
GPU 없음 / 1GbE / 프롬프트 0.5~4K 토큰. 목표는 논문을 쓰는 것이다.

## 이미 다루고 있는 개념 (lesson 의 concepts 는 되도록 여기서 고른다)
{CONCEPTS}

## 이번에 레슨을 채울 과목
{COURSE}

## 출력 형식
JSON 객체 하나만. 코드펜스 없이.

{"course_id":"<주어진 id 그대로>",
 "summary":"<이 과목을 한 문장으로>",
 "lessons":[{"id":"<과목id-01 형식>",
             "title":"<레슨 제목. 구체적으로>",
             "one_liner":"<이 레슨에서 배우는 것. 한 줄>",
             "minutes":<예상 학습 시간(분). 20~90 사이. 내용 분량에 맞게>,
             "concepts":["<관련 개념 key. 위 목록에 있으면 그것을, 없으면 넣지 않는다. 0~4개>"],
             "quiz_topics":["<이 레슨에서 낼 수 있는 문제 주제 2~3개>"]}]}

## 규칙
- 레슨 수는 주어진 개수를 **정확히** 맞춘다.
- 쉬운 것부터 어려운 것 순으로 배열한다. 앞 레슨이 뒤 레슨의 준비가 되게 한다.
- 이 학생의 연구(CPU 추론, prefill, 분산)와 이어지는 내용을 우선한다.
  단, 과목의 정체성을 잃지 않는다 — 컴퓨터 비전 과목을 LLM 과목으로 만들지 않는다.
- concepts 는 위 목록에 실제로 있는 key 만 쓴다. 없으면 빈 배열로 둔다.
- 한국어. 제목은 간결하게, 군더더기 없이.
